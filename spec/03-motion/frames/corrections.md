# Corrections / additions to the earlier 03-motion docs (earlier files left untouched)

1. `residence-02.md` pieces: "`.ap-piece` (4 per room ...)" lists 5 items and the DOM has 15 `.ap-piece` nodes = 5 per room (eyebrow, 2 headline lines, paragraph, details). Index room k pieces as `5k .. 5k+4`.
2. `residence-02.md` state 1: the "next" thumbnail (second room, `74,78.6,8.6,18`) ends at opacity 0.9, not 1, because its `wait -> next` tween runs t+.6 for .9 s while the `s1` label is at t+1.2 and `tweenTo('s1')` stops there. It reaches 1 only in state 2 (as the next of room 2). Same on mobile (.901). Optional to copy; either is visually negligible.
3. `tour-teaser.md` trigger: plays when the pin starts under normal scrolling, but a large scroll jump (programmatic or fast scrollbar drag) starts it early (seen from 22500, even 21500 after a jump from 0). It is not re-triggered and does not reverse; box stays full-bleed. Rest geometry (before play) measured 893x648 at page y 23256 = 62% x 72%, left 19%, top 14%.
4. `loader-boot.md` / SHARED board ("stalls at 99", "browser agent saw loader stuck"): the boot loader is not stalling; `requestAnimationFrame` is throttled to ~0 fps while the Browser pane is hidden, which freezes GSAP and the loader counter. When the pane is awake (screenshot call) the loader reaches 100 and its `z-[200]` element ends `display:none` in a few seconds. Also `window.lenis` exists but exposes only `{version}`.
5. Viewport emulation: `resize_window` with explicit width/height followed by a reload does change `innerWidth` (768, 375, dpr 2); the earlier "stays at 1440" note in the assets-seo DONE line (approximate mobile image rects) can be re-measured with this method.
6. `overview.md` / `about-cloud-parallax.md`: no numeric error found. Clarification: the ease names are right because GSAP `power2` is cubic (t^3) and `power3` quartic (t^4); do not translate them to CSS `ease-in`. The hero content fades with `power2.in` (cubic): y(41 px) = -4 = -80*(41/111)^3.
7. `marquee-transition.md`: confirmed unchanged (card, prompt, track, HUD, view boundaries, progress bar, rail). Additional measured scroll windows: prompt gone at +270 px; track gone at +720 px; HUD on at 911 px (p .11); first view change at y 7561; last view from y 12132.
