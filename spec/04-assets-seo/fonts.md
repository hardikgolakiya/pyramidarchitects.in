# Fonts

Two Google Fonts loaded via `next/font/google` (self-hosted woff2, served from `/_next/static/media/`). Open licence (OFL), may be reused.

| Family | CSS var | Tailwind use | Styles / weights |
|---|---|---|---|
| Familjen Grotesk | `--font-familjen-grotesk` | default sans (`font-sans`, body) | variable, `font-weight: 400 700`, normal only |
| Instrument Serif | `--font-instrument-serif` | `.font-serif` (headings, display italic accents) | single weight 400, **normal + italic** |

Variables are applied on `<html>` as classes: `familjen_grotesk_f0527726-module__vHdTJa__variable instrument_serif_72bbfbb4-module__cRt5FG__variable h-full antialiased`.
Resolved variable values:
```
--font-familjen-grotesk: "Familjen Grotesk", "Familjen Grotesk Fallback";
--font-instrument-serif: "Instrument Serif", "Instrument Serif Fallback";
--font-mono: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace; (Tailwind default)
```
Body rule: `font-family: var(--font-familjen-grotesk), sans-serif`. Weights actually used by Tailwind utilities in the CSS: `--font-weight-normal:400`, `medium:500`, `semibold:600`, `bold:700` (headings mostly `font-medium`).

## Rebuild config (next/font)
```ts
import { Familjen_Grotesk, Instrument_Serif } from 'next/font/google';
export const familjen = Familjen_Grotesk({ subsets: ['latin','latin-ext','vietnamese'], variable: '--font-familjen-grotesk', display: 'swap' }); // variable weight 400-700 by default
export const instrument = Instrument_Serif({ subsets: ['latin','latin-ext'], weight: '400', style: ['normal','italic'], variable: '--font-instrument-serif', display: 'swap' });
// <html lang="en" className={`${familjen.variable} ${instrument.variable} h-full antialiased`}>
```
Tailwind v4 `@theme`: `--font-sans: var(--font-familjen-grotesk); --font-serif: var(--font-instrument-serif);`. Preload is automatic in the layout (only the latin subset files get `.p.`).
No other webfonts, no icon fonts (icons are inline SVG). No `font-display: optional`; swap with size-adjusted fallbacks limits CLS.
