# SEO, routing, headers, caching

## Platform
Next.js App Router built with Turbopack, deployed through **OpenNext on Cloudflare** (`server: cloudflare`, `x-opennext: 1`, `x-powered-by: Next.js`, `alt-svc: h3`, Cloudflare Web Analytics beacon `static.cloudflareinsights.com/beacon.min.js` + `/cdn-cgi/rum`). HTML is delivered zstd-compressed (12.5 KB over the wire for 71,471 B decoded on `/`).

## Routes
| Route | Status | Notes |
|---|---|---|
| `/` | 200, static prerender | single-page scroller with anchors `#top`, `#about`, `#marquee-transition`, `#residence-slides`, `#residence-02`, `#residence-02-tour`, `#contact` |
| `/tour` | 200, static prerender | 3D walkthrough client app |
| `/robots.txt`, `/sitemap.xml`, `/favicon.ico` | 200 | static files |
| anything else (e.g. `/nonexistent`, `/images/still-form-social.jpg`) | 404, `content-type: text/html`, `cache-control: private, no-cache, no-store, max-age=0, must-revalidate` | default Next 404 page |

Navigation links: `/`, `#marquee-transition`, `#residence-02`, `/tour` (nav); footer anchors `#residence-slides`, `#residence-02`, `#top`. Social links open `target="_blank" rel="noreferrer"` (they are the original developer's profiles; replace with client links).

## robots.txt (exact)
```
User-agent: *
Allow: /

Sitemap: https://stillform.homes/sitemap.xml
```
Headers: `content-type: text/plain`, `cache-control: public, max-age=0, must-revalidate`.

## sitemap.xml (exact structure; generated by `app/sitemap.ts`)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://stillform.homes/</loc><lastmod>2026-10-14</lastmod><changefreq>monthly</changefreq><priority>1.0</priority></url>
  <url><loc>https://stillform.homes/tour</loc><lastmod>2026-10-14</lastmod><changefreq>monthly</changefreq><priority>0.8</priority></url>
</urlset>
```
(pretty-printed one tag per line in the original). Header `content-type: application/xml`. Rebuild with `MetadataRoute.Sitemap` and `app/robots.ts`, swapping the domain.

## Heading outline (`/`)
Only one `<h1>`, then h2s, with one `<h3>` (HUD label) between. Text is split into line/word spans for animation (the inner text collapses in the outline, e.g. "Space,Considered."); copy itself belongs to the content spec.
```
nav (fixed, mix-blend-difference): wordmark link, MENU links (Residence #marquee-transition, Stays #residence-02, Tour /tour)
main#top
  section (hero, sticky, 100svh)      h1  font-serif clamp(2.75rem,12vw,4.5rem)  "Space, considered."
  section#about                        h2  "A study in form, light and proportion."
  section#marquee-transition           h3  [data-hud-text] "Full View"  (HUD label, not a real subsection)
  section#residence-slides             h2  "Rooms that hold the evening light."   h2 "Not every space needs to be grand."
  section[aria-label="Transition from villa to apartment"]  h2.ap-transition-heading  "A different way to stay."
  section#residence-02                 h2 "Everything within reach."  h2 "Slow mornings, softly lit."  h2 "Room for one more."  (first h2 is the big title clamp(2.75rem,12vw,5.5rem), next three clamp(1.75rem,6.5vw,2.75rem))
  section#residence-02-tour            h2 "Step inside."  (+ link to /tour)
footer#contact                         h2 "Space, considered." (footer-reveal, font-serif clamp(3rem,13vw,...), max-w-[12ch])
```
Outline problems to improve: h3 appears before any h2 content in its section; the same phrase is the h1 and the footer h2. `/tour` has no h1 (only an h2 "Turn your device, sideways." on the portrait lock screen); add an h1 (visually hidden is fine).

Landmarks: `<nav>`, `<main id="top" class="overflow-x-clip">`, `<footer id="contact">`, one `<section aria-label="Transition from villa to apartment">`. No skip link, no `aria-current`.

## Structured data
None: no `application/ld+json`, no microdata. Recommended for the rebuild (client is an architecture practice): `Organization`/`ArchitecturalService` (name, url, logo, sameAs, address), `WebSite`, optionally `BreadcrumbList` for `/tour`. Place with `<script type="application/ld+json">` in the layout.

## HTTP headers
| Resource | cache-control | Other |
|---|---|---|
| HTML `/`, `/tour` | `s-maxage=31536000` (browser revalidates, edge caches 1 year; `x-nextjs-cache: MISS`, `x-nextjs-stale-time: 300`) | `vary: rsc, next-router-state-tree, next-router-prefetch, next-router-segment-prefetch`; `content-type: text/html; charset=utf-8` |
| `/_next/static/**` (js, css, media) | `public, max-age=31536000, immutable` (value is duplicated by the proxy: `public, max-age=31536000, immutable, public,max-age=31536000,immutable`) | brotli for css/js (`content-encoding: br`) |
| `/assets/images/*.webp`, other `/assets/*` | `public, max-age=604800` (7 days) | Cloudflare HIT, strong ETag |
| `/robots.txt`, `/sitemap.xml`, `/favicon.ico` | `public, max-age=0, must-revalidate` | ETag |
| 404s | `private, no-cache, no-store, max-age=0, must-revalidate` | |
Missing hardening headers (absent in the reference): no CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy. `report-to`/`nel` come from Cloudflare. Recommended for the rebuild: add `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, and lengthen `/assets` caching (e.g. 1 year `immutable` with hashed filenames, or at least 30 days).

## Indexing considerations
- No `noindex`; whole site crawlable. The Three.js tour is client-rendered, so `/tour` has little text; give it a descriptive intro paragraph server-side.
- Canonical issue on `/tour` (see favicon-meta.md).
- `lastmod` is static (2026-10-14): in the rebuild derive from build date or git.
- Language: `<html lang="en">`; OG locale `en_US`. No hreflang.
